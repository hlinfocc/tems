# 评教小程序管理系统

## 系统介绍

评教小程序管理系统是一个用于学生评教（学生对教师教学评价）的综合性平台，包含小程序端和管理后台。该系统旨在简化评教流程，提高评教数据的收集、管理和分析效率，为教育教学质量监控提供有力支持。

### 主要特点

- 学生端小程序提供便捷的评教功能
- 管理后台支持轮播图、评教任务、问卷和结果的全面管理
- 完善的用户认证和权限控制
- RESTful API 设计，支持前后端分离架构

## 系统功能

### 小程序端功能

1. **学生登录与绑定**

   - 手机号登录认证
   - 学生信息绑定（姓名、学号、班级）
   - JWT 令牌管理

2. **评教功能**

   - 查看当前评教任务
   - 填写评教问卷
   - 提交评教结果

3. **轮播图展示**
   - 首页轮播图展示学校通知或活动信息

### 管理后台功能

#### 1. 首页看板
- 系统总览页面
- 数据统计与分析

#### 2. 学生管理
- 学生信息管理，使用抽屉模式处理添加和编辑操作

#### 3. 课程管理
- 课程信息管理

#### 4. 班级管理
- 班级信息管理，使用抽屉模式处理添加和编辑操作

#### 5. 评教问题管理
- 评教问题集管理
- 评教问题详情管理 : 具体评教问题内容管理

#### 6. 评价任务管理
- 评价任务的创建、分配和管理，使用抽屉模式处理添加和编辑操作

#### 7. Banner管理
- 小程序轮播图管理

#### 8. 用户管理 
- 用户列表和基本信息管理

## 技术栈

### 后端技术栈

- **语言**: Go
- **Web 框架**: Gin
- **数据库**: 关系型数据库(通过 GORM 操作)
- **认证**: JWT (JSON Web Token)

### 前端技术栈

- **小程序**: 微信小程序原生开发
- **Web 管理端**: openTiny Pro

## 开发说明

### 环境要求

- Go 1.24+
- PostgreSQL 13+
- 微信开发者工具

### 安装与运行

#### 后端服务

1. 配置数据库连接信息
2. 运行 `go run main.go` 启动 API 服务

#### 小程序

1. 使用微信开发者工具导入 mini 目录
2. 配置 API 接口地址
3. 编译运行小程序
